# Native ablation artifacts

`fixtures.json` pins the 11 previously prepared snapshots and 9 additional cases. Fixture bodies remain under ignored `rust/fixtures/`; `tools/ablation_fixtures.py` rebuilds or verifies them from the archived local data sources. The other benchmark workspace is not an output location.

`checks.json` records the Rust tests, strict Clippy, release build and source/binary hashes. `differential.json` records 4,772 complete-trace comparisons against the independent Python recount oracle, with 16 explicit rejections of an initial alphabet too large for the u16 layouts. Rejections are reported separately from successful comparisons.

`pilot-*.jsonl` are development probes with one sample per combination. They preceded source freeze, may include concurrent build activity, and are not inputs to the formal conclusions. Their environment sidecars preserve the actual recorded provenance.

The formal matrix is generated sequentially by `tools/run_ablation_matrix.py`; its commands are persisted in `formal/commands.json`. Every timed combination uses five fresh processes in shuffled order, with no concurrent build or separate benchmark launched by this task. Scalar jobs are pinned to CPU 5, parallel jobs may use CPUs 0–5. This is a shared 6-vCPU KVM environment with one visible NUMA node, not a dedicated dual-socket server.

| Archive | Coverage |
|---|---|
| `formal/scalar.jsonl` | 25 scalar versions × 18 cases × checked/unchecked × 5 repetitions = 4,500 runs |
| `formal/continuous-scalar.jsonl` | Six scalar references × two unsplit 4 MiB texts × two bounds modes × 5 = 120 runs |
| `formal/parallel.jsonl` | Eight parallel versions × seven cases × 1/2/4/6 requested workers × 5 = 1,120 runs |
| `formal/parallel-unchecked.jsonl` | Snapshot and three adaptive versions × three cases × 1/4 workers × 5 = 120 runs; checked counterparts are in the preceding archive |
| `formal/topology.jsonl` | Eleven components × ten lengths × three merge patterns × two bounds modes × 5 = 3,300 rows; 150 rows explicitly skip u8 lengths above 255 |

The continuous scalar matrix deliberately uses six references rather than repeating all 25 layouts there; every scalar variant is measured on all 18 other cases. The additional unchecked parallel matrix covers the modes with a distinct unchecked atomic path. All variants and worker counts also participate in correctness checks.

Each JSONL has an `.environment.json` sidecar identifying the binary, measured sources, input hashes, runtime configuration and repetition count. `train_seconds` covers initialization and merging; `call_seconds` also includes input validation, final extraction and destruction; the outer subprocess time additionally includes fixture parsing and fingerprint construction. `call_cpu_seconds` sums CPU use across threads. `vm_hwm_mib` is process peak resident memory, including fixture-loading and conversion peaks. Buffer counts are separate component metrics.

`summary.json` and `summary.md` are generated by `tools/ablation_summarize.py` from the four formal training archives, excluding pilots and component-only timings. They contain all per-case medians/ranges, semantic fingerprint checks, pairwise reference ratios and observed time/RSS Pareto fronts. Microbenchmarks are analyzed separately because ByteSpans and u8-only store topology, while the other components also handle token IDs.

`topology-summary.json/.md` validates all 3,300 micro rows separately. `certificate-probe.jsonl` is a later 80-run, single-repetition semantic/batch-width diagnostic from native source `1c2fffc`; its new binary is not combined with the formal timing matrix. `certificate-summary.json/.md` excludes timing comparisons and reports identical checked/unchecked batch counters. `certificate-differential.json` records 448 additional full-trace checks; `certificate-checks.json` records the native checks and hashes.

The first matrix varied requested worker count with the same six-CPU affinity throughout; workers may have an additional coordinator. It is not a strict p-core budget experiment. The runner now supports `--parallel-core-budget workers`, binding the whole process to p CPUs (including the coordinator), with p=1 using the same CPU as the scalar reference. `affinity-smoke.jsonl` checks the 1/4-CPU protocol only; it is not formal speed evidence.

To reproduce the exact first source version, use an isolated checkout/worktree at `b97666b`. The current branch adds the diagnostic probe. Archived `formal/commands.json` preserves the explicit original variant lists. Derived summaries now reject mixed-binary input; unused helper hashes can differ between stages without changing the measured Rust binary. The original micro helper and certificate-time differential helper snapshots are retained under `runner_snapshots`.

Reproduction writes to a new directory and refuses to overwrite archived results:

```sh
cargo build --manifest-path rust/Cargo.toml --release --bins --locked
python rust/tools/run_ablation_matrix.py \
  --output-dir rust/ablation_results/reruns/example --repeats 5
```

See [the report](../ABLATION_REPORT.md) for interpretation and the exact limits of the comparisons.
